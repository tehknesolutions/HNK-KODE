# M36 Registry Acceptance

Repository acceptance for Issue #128 requires:

1. valid M35 imported bundles can be registered and retrieved by digest;
2. invalid/unverified inputs are rejected;
3. exact duplicates remain one unique registry entry;
4. conflicting preserved content under an existing digest is rejected;
5. returned entries/stage maps and snapshots are frozen;
6. public export and verification ledger are present;
7. documentation does not equate registration with execution, authority, or canon.

Executable test evidence is tracked separately from static acceptance.
