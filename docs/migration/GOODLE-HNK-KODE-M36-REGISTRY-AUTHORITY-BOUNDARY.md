# M36 Registry Authority Boundary

`REGISTERED` means only that an M35-verified conformance bundle has been cataloged under its verified digest.

It MUST NOT be interpreted as:
- manifestation execution;
- successful runtime evidence;
- permission to execute;
- Creator/canon approval;
- governance authority;
- semantic truth beyond the preserved verified record.

This separation is intentional and remains part of the M36 registry contract.
