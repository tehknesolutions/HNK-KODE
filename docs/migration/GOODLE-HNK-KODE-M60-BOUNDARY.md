# M60 Authority Boundary

M60 answers one question: whether a specific canonical M59 archive-registry state is cryptographically bound to a deterministic digest.

It does not answer whether any manifestation ran, succeeded, deployed, executed, or produced runtime evidence.

Therefore:

`M60_SEALED` ⇒ registry integrity artifact

`M60_SEALED` ⇏ `EXECUTION_EVIDENCE`
