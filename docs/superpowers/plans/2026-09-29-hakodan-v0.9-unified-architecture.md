# haKodan v0.9 Unified Narrative Architecture Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the existing haKodan compiler with narrative semantic sentences, governed discovery, reactive graphs, multimodal projections and manifestation/lowering contracts without creating a parallel compiler.

**Architecture:** Extend the current parser → AST → HOM → HNK-IR pipeline with focused v0.9 modules. Semantic IDs remain authoritative across textual, block and glyph surfaces; authority/provenance and discovery state gate effects and canon transitions.

**Tech Stack:** Node.js ESM, `node:test`, JSON registries, existing haKodan parser/HOM/HNK-IR/VM modules.

**Spec:** `docs/superpowers/specs/2026-09-29-hakodan-v0.9-unified-architecture.md`

## Global Constraints
- Source accepts HNK, PT-BR, EN, or mixed forms.
- PT-BR accepts accented/ç and normalized equivalents.
- Existing AST/HOM/HNK-IR is extended, never replaced.
- Semantic ID outranks morphology, glyph and phonetic resemblance.
- Generated discovery cannot silently become CANON.
- `INTENT → PLAN → MANIFEST` gates effects.
- v0.8 and earlier tests remain green.

## Review Focus
- Compact and explicit sentence forms must lower equivalently.
- Mixed-language source must preserve Semantic IDs.
- AI/discovery proposals must not bypass authority transitions.
- Reactive dependency cycles must diagnose rather than recurse forever.
- Lifting from lower representations must preserve inferred/lifted provenance.
